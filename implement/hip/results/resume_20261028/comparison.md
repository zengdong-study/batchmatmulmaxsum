# Small / Split-B 同机续测结果（2026-10-28）

所有耗时来自 gfx1100 同一设备、现有持久化 case；10 次预热、单次包含 100 调用的 HIP Graph replay，device event elapsed/100 算术平均。搬运、分配、捕获、验证不计时；重复一致性额外检查位于正式测量之后。每次融合调用仍只有一个 kernel。

最终拆分基线采用baseline_isolated中34case的完整独立重测；首轮大B基线与另一任务日志时间交叉，故全部重测排除干扰。首轮及case11/15诊断性复核保留，不按多轮最小值择优。

Small Matrix 保持 22 个 case；Split-B 主计时 case9–16 各12配置，case37–40只测 gb1_w4_n64；不测 case33–36。表中“优化前”是暂停时协作加载源码在本轮设备上的复建版本，历史结果保留，不将不同 GPU 标识的记录拼成一轮。
