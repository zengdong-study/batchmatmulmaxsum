# S1：host 按输入元数据选择单 kernel 路径

固定策略版本：S1-v1。入口头文件为 `include/bmms/s1_c.h`，实现为 `src/s1_entry.hip`。拿到输入后，调用方提供实际B/M/N/K、FP16或BF16、两项存储布局标志；入口在CPU上计算路径，再启动选中的一个GPU kernel。不会读取输入数值、case编号、golden或计时记录来分派。

`bmms_s1_plan` 是纯host查询，用于在输入元数据确定后取得route、workspace字节数及计数器偏移；失败不修改输出参数。`bmms_s1` 使用同一host策略验证问题并提交一次调用。它不依赖测试工具选路，不执行GPU分派kernel。Graph捕获时host已选定路径；换形状/布局须重新规划和捕获，不能通过旧graph自动改路。

## 固定规则（按表中优先级）

| 条件 | 路径/参数 | 工作区前提 |
|---|---|---|
| 显式允许初始化，B4/M32/N1024/K128 | Split-N group64/waves2 | 条件路径 |
| 显式允许初始化，N=1且M>128 | Split-M group64/waves4 | 条件路径 |
| B≤8、M≤128、N≤257 | Small Matrix，沿用原host的wave规划 | 无外部计数器初始化 |
| B4/M32/N1024/K128，未启用条件路径 | Split-B gb1/w8/n32 | 无外部计数器初始化 |
| B64/M8192/N8192/K128 | Split-B gb1/w4/n64 | 无外部计数器初始化；本轮只做host路由核对 |
| 其余 | NotImplemented | 不启动kernel |

仍受底层接口范围和dtype校验约束。这里的规则适用于元数据，不代表表内任意未测输入均已通过正确性或性能验收。N=1且M小的输入继续走Small，保留原case25的胜出路径。

条件路径必须由调用方显式传 `allowInitializedWorkspace=1`。默认传0；原case27/32在此模式下返回NotImplemented，不能宣称已无条件覆盖。第一次使用前，设备workspace需256-byte对齐，并在同一stream顺序上将 `workspace + counterOffset` 处B个uint32清零；部分结果区无需初始化。允许连续调用/replay；并发调用使用独立workspace/output；失败、未完成或布局改变后重新初始化。首次初始化是否符合最终评测接口仍未获得题面明确依据。

每次成功调用仅有一个计算kernel；接口本身不分配、不复制、不清零、不做设备同步。底层Small/Split-B与独立Split-M/N接口继续保留，可直接回退。

## 构建

```bash
cmake -S implement/hip -B /tmp/bmms-s1-build \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_HIP_COMPILER=/opt/rocm/llvm/bin/clang++ \
  -DCMAKE_HIP_ARCHITECTURES=gfx1100 -DBMMS_BUILD_S1=ON
cmake --build /tmp/bmms-s1-build -j2
```

S1为可选目标，默认OFF。开启后生成 `libbmms_s1.so`，依赖同构建中的 `libbmms_small.so` 与 `split_mn/libbmms_split_mn.so`。

## 小范围验证与续跑

```bash
/opt/venv/bin/python implement/hip/tools/s1_runner.py \
  --mode validate --ids 1 9 11 15 27 32 \
  --output implement/hip/results/my_s1 --max-cases 2
# 保持相同ids、源码、库和环境，重跑同一命令会跳过已验证项目。
# 验证通过后，以相同ids/output运行 --mode time；可继续用 --max-cases 限制新增项。
```

工具在同一进程中持有共享按BDF GPU锁并审计管理接口与DRM客户端。输出包含源码/库/数据/环境身份、逐项原子结果和每次运行审计；正式计时严格10预热/100次device执行，并在计时外核验golden和额外replay。恢复时，原项必须有完整有效的审计。中断或受干扰的记录保留但不得复用，换新目录重测；不能挑选多轮最小值。

本次32case逐项结果、回退、机器码资源与6次调用的单kernel证据见 [S1报告](results/s1_20261029_v1/S1报告.md)。计时只报告device均值，没有测host端到端延迟。
